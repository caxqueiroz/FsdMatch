# Changelog

## v1.0.0 - 2026-05-17

- Added `fsdtrace trace github <url> --fsd <path>` to download a public GitHub repository and run the full trace pipeline.
- Added Spring PetClinic example requirements at `examples/petclinic/fsd.md`.
- Added `task trace-github` shortcuts for source checkouts and release archives.
- Added flexible Bedrock embedding adapters with Titan as the default and Cohere Embed v3/v4 support.
